# طرح ۷ — Solar Canvas | برقتو

**A Persian solar-energy concept built around rich sun imagery and a storytelling layout.**

> **نوع پروژه:** طرح مستقل UI/UX و فرانت‌اند استاتیک، مناسب بررسی و مقایسه ایده‌های طراحی؛ نه سامانه عملیاتی فروش یا پایش برق.

## هدف طراحی

داستان‌پردازی تصویری درباره انرژی خورشیدی و تبدیل تابش به درآمد. این طرح برای بررسی زبان بصری و روایت دیجیتال خدمات تجمیع برق خورشیدی برقتو ایجاد شده است.

## عناصر شاخص

- هیرو «نور را به درآمد تبدیل کن» و روایت مرحله‌ای
- بخش پایش، فروش رقابتی و تسویه شفاف
- محاسبه‌گر نمونه و المان‌های تعاملی
- تصویر خورشید و ویدیو در پوشه assets

## فناوری و فایل‌ها

- **HTML / CSS / JavaScript** — کد این نسخه در فایل `index.html` تجمیع شده است.
- **کتابخانه‌ها و منابع:** GSAP، ScrollTrigger، Lenis، فونت Vazirmatn و فایل‌های `assets/sun-nasa-sdo.jpg` و `assets/sun-real.mp4`.
- رابط فارسی راست‌به‌چپ، مناسب مشاهده در مرورگرهای جدید.


## پیش‌نمایش آنلاین / Live demo

**[اجرای آنلاین tarh-7](https://babakbinesh23.github.io/tarh-7/)** — صفحه GitHub Pages در بررسی ۲۱ نوامبر ۲۰۲۶ قابل دسترسی بود. نمایش صحیح همه تعاملات و اتصال فرم‌ها جداگانه باید تست شود.

## اجرای محلی

از ریشه مخزن، فایل `index.html` را در مرورگر باز کنید. برای پیش‌نمایش با سرور استاتیک:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. نیاز به npm، دیتابیس یا فرآیند Build نیست. انیمیشن‌ها و فونت‌های CDN برای نمایش کامل نیاز به اینترنت دارند.

## محدودیت‌ها و ملاحظات

- پیش از بازنشر تصویر/ویدیوی خورشید، منبع، اعتباردهی و مجوز انتشار آن‌ها را جداگانه تأیید کنید؛ وجود فایل در مخزن به‌تنهایی به معنی مجوز بازتوزیع نیست.
- محاسبه‌های مالی/فنی و آمار باید قبل از استفاده واقعی با داده معتبر راستی‌آزمایی شوند.
- برای اتصال فرم‌ها به CRM، احراز هویت، ثبت داده و مدیریت اطلاعات شخصی به بک‌اند ایمن نیاز است.
